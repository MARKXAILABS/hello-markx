| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-03-02a | Information Disclosure | `control:breakerSnapshot` response | accept | Returns only `agentId`/`level`/`reason`/`ts` — the same fields `control:setBreakerState` already pushes to every window; no new sensitive field is added |

| T-03-02c | Tampering | `spawnedAt` reset on respawn | accept | `spawnedAt` is derived server-side from `Date.now()` at spawn time only, never renderer-supplied — no injection surface |
