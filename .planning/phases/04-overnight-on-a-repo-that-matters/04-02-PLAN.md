<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| agent-authored text → `tool_calls.target` | The command string an LLM-controlled shell wrote crosses into durable storage. It is untrusted on write and untrusted again on read-back. |
| `hive.appendLog` payload → `events.json` | Whole hive events, some carrying agent-authored fields, stored verbatim. |
| `harness.db` on disk | Lives in `userData` alongside config; contains a record of everything the floor ran. **It is outside the hive root, so `protectedPathDenial` never sees a path to it — `rootTailVerdict` only compares children of the hive root against its protected literals. An agent that can reach `%APPDATA%` can read and delete the audit trail of its own tool calls.** |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-LOG-01 | Tampering | SQL injection through `target` / `kind` / `json` | mitigate | Bound parameters only in all five methods; acceptance criterion asserts no `${` interpolation in any new SQL string (ASVS V5, V7) |
| T-04-LOG-02 | Tampering | Log injection — `target` re-rendered as markup or a control sequence | mitigate | Stored raw, escaped at render; the migration comment states it is untrusted text and must never be `eval`ed. Rendering is out of this plan's scope and is stated as such |
| T-04-LOG-03 | Denial of service | Unbounded `target` column from a 16 MiB `HOOK_LINE_MAX` payload | mitigate | Explicit byte cap on `target` before insert, number stated in the comment |
| T-04-LOG-04 | Denial of service | Unbounded `events` growth | mitigate | `pruneEvents(olderThanMs)` as a query bound (D-18), default 30 days, run by a caller in a later plan |
| T-04-LOG-05 | Repudiation | "The record survives the crash" proved by a WAL read that would not survive power loss | accept | `synchronous = NORMAL` is the right trade for this app; the ceiling is **written into the code comment and the SUMMARY** rather than silently upgraded to `FULL` (RESEARCH Pitfall 5) |
| T-04-LOG-06 | Information disclosure | Raw OTel records / PII entering the store | mitigate | `hive.ts:2517-2522` already forbids persisting raw OTel records; this plan adds no OTel path at all — the telemetry ring is untouched (`04-PATTERNS.md`: NO SOURCE CHANGE RECOMMENDED) |
| T-04-SC | Tampering | npm/pip/cargo installs | mitigate | No install step. `better-sqlite3` 13.0.3 already in `dependencies`; `04-RESEARCH.md` § Package Legitimacy Audit records zero packages proposed |
