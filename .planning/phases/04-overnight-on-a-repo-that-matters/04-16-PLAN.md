<objective>
GATE-05's shim half: the bounded wait that times out to **deny**, built as a poll because a measurement
says the obvious alternative is a silent fail-open.

**Purpose.** Plan 04-15 made main answer an ask with a reply that is simultaneously a deny for an old shim
and a `hive_ask` handle for a new one. This plan teaches the three reply-reading shims to see the handle
and poll.

**L-02 is why this is a poll and not a stream, and it is not a preference.** Measured:
- `HOOK_SHIM` (`hiveTemplates.ts:341-345`): `c.on('data', d => resp += d)`, `c.on('end', () => done(0))`,
  and `done` writes `resp` to stdout verbatim.
- `GROK_HOOK_SHIM` (`:770-784`): `done` runs `JSON.parse(resp || '{}')` over the **whole accumulated
  buffer**; on a parse failure it sets `out = null` and `process.exit(0)` **with no stdout — which is
  allow**.
- `AGY_HOOK_SHIM` (`:364-412`): the same shape.

A "pending" preamble written on the live connection followed by a verdict produces
`{"pending":…}{"deny":…}` in `resp`. `JSON.parse` throws. **grok and agy then exit 0 silently, which is
allow.** A streaming implementation would pass every Claude test and silently allow on two of the seven
engines. Do not let this plan be "simplified" into holding the connection.

**S-2 sequenced this after plan 04-10 for a reason, and there is a commit hazard to carry.**
`gitCommitter.ts:238-248`'s `harnessAuthored` byte-compares `bin/cth-hook.cjs` against the `HOOK_SHIM`
constant — *against the INDEX blob (`git show :path`), not the working file.* Changing the constant is
fine: `hive.ts:801` rewrites the file every bootstrap. **But the constant change and any regenerated
committed shim must land in the SAME commit, or the secret-scrub sees a mismatch and the false positives
it exists to suppress come back.**

**Pitfall 6 — the trap.** Flipping the shim's existing 5 s `setTimeout(() => process.exit(0), 5000)`
(`hiveTemplates.ts:347`) to a deny is the obvious way to make the wait fail closed. It would make **every
socket outage, every app restart, and every legitimately-not-running floor deny every tool call on every
agent.** The 5 s timer is untouched for the non-ask path; the deadline replaces it only once `hive_ask` is
seen.

**Output.** A poll loop in three shims, and the integration test that observes all three outcomes on real
stdout.
</objective>
