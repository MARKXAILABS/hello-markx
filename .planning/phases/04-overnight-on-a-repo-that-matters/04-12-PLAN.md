<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ledger data → rendered card text | `task.title`, `task.assignee`, `released.by` and `released.branch` are all written by agents or derived from agent-controlled paths. React escapes text children by default; a `title` attribute is likewise inert. Nothing here uses `dangerouslySetInnerHTML`. |
| stored timestamps → derived age | The only computation. A malformed or future timestamp must degrade, not throw. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-AGE-05 | Tampering | Agent-authored text (a card title, a branch name) rendered as markup | mitigate | React text children and `title` attributes only; no `dangerouslySetInnerHTML` anywhere in this plan. `wordBreak: 'break-all'` on the branch prevents layout-breaking long strings without HTML |
| T-04-AGE-06 | Denial of service | A malformed or future `updatedAt` producing `NaNs` or throwing during render | mitigate | `relAge` degrades to `0s` for negative and NaN inputs; asserted in task 1 |
| T-04-AGE-07 | Repudiation | An age derived from `createdAt` silently presented as a last-change time | mitigate | Rule A-3: the tooltip names which clock it read (`created … — never updated`); asserted |
| T-04-CARD-06 | Repudiation | A branch placeholder indistinguishable from a real branch named `unknown` | mitigate | Rule R-1: absence is the rendering. The test asserts the **absence** of any placeholder token |
| T-04-AGE-08 | Denial of service | A geometry change on a frozen 322×86 agent card or a 170px kanban column | mitigate | The meta row already exists and becomes unconditional — no new row, no height change. `AgentCard.tsx` diff asserted empty |
| T-04-SC | Tampering | npm/pip/cargo installs | mitigate | No install step. No new icon (`clock` is already among `Icon.tsx`'s 22 names), no new token, no new component. `04-RESEARCH.md` § Package Legitimacy Audit records zero packages proposed |
</threat_model>
