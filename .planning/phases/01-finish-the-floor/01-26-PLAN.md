<objective>
**This revision does NOT widen the value matcher. That is the deliverable.**

Three consecutive revisions tried to widen `redactSecrets` to cover JSON `"token": "…"`, and each one
had to bolt a value-shape predicate onto pattern 5 to keep the false positives out. Measured, twice:

- revision 2's predicate turned **four** credential classes that redact at HEAD into plaintext;
- revision 3's re-derived predicate fixed those four and turned **eleven more** into plaintext.

That is not two unlucky regexes. Credentials and identifiers are not separable by value shape, so every
predicate that kills a false positive kills a real detection. And the loss is not symmetric with the
gain: `hive.ts`'s `scrubStagedSecrets` does not refuse a commit on a hit, it calls `unstagePath` and
**drops the file from history forever**, logged as `secret-scrubbed` — a line an operator cannot tell
apart from a real credential catch. A false positive destroys an agent's work silently and permanently.

**The decision, argued in `<measured_evidence>` A–D and taken this session:**

1. **Pattern 5 is byte-frozen.** No adjudicator, no `vq`, no value-shape rule, no quoted-key arm. Frozen
   means pinned: a test asserts the shipped regex literal equals a constant captured at HEAD.
2. **Only prefix changes, never value changes.** Pattern 3's `sk-` arm is SPLIT — the vendor-segmented
   `sk-ant-` half stays UNBOUNDED, the ambiguous bare `sk-` half gets the `\b` — and the six other
   alternatives are left exactly as they are. The two underscore-prefix arms
   (`\bsk_(?:ant|live|test|proj)_…`, `\brk_(?:live|test)_…`) become their OWN `s = s.replace(`
   statements AFTER pattern 5, not extra alternatives inside pattern 3. Measured non-subtractive over 38
   credential shapes, 481 tracked text files and 400 commits — and `<measured_evidence>` C and D record
   what the two rejected shapes lost, because "appending cannot subtract" is FALSE and this revision
   exists because of it.
3. **FLOOR-04 is restated as BOUNDED, with the measured ceiling**, because *"so it never reaches git
   history"* is not a property any regex has, and this plan has now measured that twice.

**The JSON arm is DROPPED, and here is the measurement that killed it.** A quoted-key/quoted-value arm,
inheriting pattern 5's own value class verbatim, gains 2 detections and costs 2 of the 12 demonstrated
false positives: `"api_key": "$OPENAI_API_KEY"` and `"secret": "REPLACE_ME"` — a config template and a
scaffold placeholder, both shapes agents write constantly, both unstaged FOREVER on a hit.
**+2 detections do not buy 2 permanent unstages. That is the whole reason, and it is a cost argument.**

It is NOT that a value-shape predicate on that arm would re-open the door that cost 15 detections. It
would not, and revision 4 said it would: the 15 were lost to a predicate on **pattern 5**, the only arm
covering labelled `key=value`, where a predicate subtracts from live detections. A predicate confined to
a newly appended arm can only reduce that arm's own gains — this plan's own append argument, applied to
itself. Rejecting the arm on a hazard that does not apply to it is how a plan ends up defending the
right decision with the wrong sentence, and the ceiling must carry the right one.
It is recorded in the ceiling as a named residual with its measurement, not shipped as a fix.

**What this plan finds that no previous revision looked for.** `redactSecrets` at HEAD fires on
**184 distinct spans across the 481 tracked text files, and NOT ONE of them is a LIVE credential** — the
credential-shaped values among them are all this repo's own synthetic fixtures, which the matcher flags
CORRECTLY. Replayed against real history: **50 of the last 400 commits (12.5%) would have had at least
one path silently dropped, across 66 distinct paths** — `src/main/hive.ts`, `src/main/index.ts`,
`src/preload/index.ts`, `src/main/config.ts`, `test/engine-parity.test.cjs`, half of `.planning/`. Every
one of those is `token: string):`, `secret: string`, `botToken: string`, or the redactor's own
`token=[redacted]` output. **FLOOR-04's control has a measured precision of zero against LIVE
credentials on this tree and a measured cost of 66 paths.** That is a larger fact than any missed shape,
it is the reason the ceiling has to be restated rather than appended to, and it is why widening the
value arm is the wrong direction of travel.

Two of those 66 this plan DOES fix, for free, with the same `\b`: `desk-backend-engineer` and
`desk-market-researcher` match pattern 3's unbounded `sk-` alternative, which unstages
`tools/mapgen/build_map.py`, `src/renderer/src/assets/maps/office.tmj`,
`src/renderer/src/scene/office/themeRegistry.ts` and `tools/mapgen/original-office.tmj` today.

Separately: `revokeProxyToken(agentId)` sits OUTSIDE the identity guard in the dying sidecar's exit
handler, so every qwen/crush restart dead-hooks its own replacement. Not a race — `kill()`'s exit event
is asynchronous and the re-mint is synchronous, so the old exit lands after the new token is in the map,
every time.

7-site naming residual.

Output: a matcher that provably loses nothing, a requirement restated to what it actually delivers, and
