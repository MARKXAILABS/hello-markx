<interfaces>
**The breaker does not work the way D-17 describes, and this is the single most important thing to
read before writing the arm.** From `src/main/breaker.ts:269-294`:

1. `evaluate()` returns `{tripping, reason}` — a **boolean, not a level**. A new arm can only say
   "trip" or "don't"; it cannot target `constrained` directly.
2. Escalation is **one rank per beat** from the current level:
   `target = LEVELS[Math.min(rank(s.level) + 1, rank(ceiling))]` where
   `LEVELS = ['healthy','steering','constrained','stopped']`. A healthy agent that goes over budget
   reaches `steering` on the first beat and `constrained` on the **second**.
3. `hardStop: false` (default at `:85`) caps the ceiling at `constrained` (`:277`). D-18 is therefore
   already the shipped behaviour — nothing gets killed, and the budget arm inherits that for free with
   no new guard.

`evaluate()` is `private`, pure, has an eight-argument signature, and its arms are an ordered
`if`-chain with early `return`. Placement decides which `reason` string the operator sees when two
conditions trip at once. Existing arm order (`:309-330`): repeated-tool-call arm, then error-storm
arm, then the per-agent token cap. **Put the budget arm after the two `(b)` storm arms and before the
floor-wide `(a)` caps** — a looping agent is a more urgent diagnosis than an expensive one, and a
per-card cap is more specific than a floor total.

`BreakerInput` (`:50-57`): `{ agentId, sample: AgentUsageSample | null, progressing: boolean }` —
D-17 widens it with `budget: {taskId, tokens, cap}`.

The `steering` arm's mail-to-assignee side effect does **not** belong in `evaluate()`; that function
is pure by design and `actionFor(level)` → `'steer'` is the established channel for side effects.

`hive:tasks` row: `ipcMain.handle('hive:tasks', () => hive.tasks())` at `index.ts:3894` — a
one-liner. The widening happens inside `hive.tasks()`. **Verified this session:
`src/preload/index.ts:779` is `hiveTasks: (): Promise<unknown> => ipcRenderer.invoke('hive:tasks')`
— the return type is already `unknown`, so this plan needs NO preload edit.** Do not open
`src/preload/index.ts`; plan 08 holds it this wave.
