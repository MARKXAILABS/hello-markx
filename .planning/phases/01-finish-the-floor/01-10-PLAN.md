## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| agent-supplied `--wing` scope → memory recall | The scope predicate is supplied by the agent asking. This is a **known, documented** weakness until RECALL-02 enforces it server-side in Phase 5; the control here is honesty, not enforcement. |
| renderer → `app:openLogs` (a path-opening IPC) | An IPC that opens a directory in the OS file manager. The handler takes no caller-supplied path, which is what keeps it safe. |
| migration DDL → a shipped user database | A bad migration can leave a user's store unusable. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-P10-01 | Information disclosure | one agent recalling another agent's or project's notes | mitigate (partially) + document | The FTS5 schema makes scope a `WHERE agent_id = ?` predicate and the cross-agent negative assertion pins it. The predicate's INPUT is still agent-supplied — RECALL-02 (Phase 5) is the real fix, and D-36 requires the docs and UI to say exactly that rather than claiming more. |
| T-P10-02 | Information disclosure | operator unaware memory defaults to shared | mitigate | `MemoryPanel` renders the `'shared'` default as a plain warning using the language already at `memory.ts:14-16`. |
| T-P10-03 | Tampering | FTS5 injection via unsanitised MATCH input | mitigate | Use bound parameters for both the MATCH term and the scope predicate; never build the query by string concatenation. |
| T-P10-04 | Denial of service | a failed or half-applied migration bricking the store | mitigate | Append-only migration inside the existing single-transaction runner; no `throw` added inside a migration; the corrupt-DB quarantine path at `db.ts:82-96` remains the backstop. |
| T-P10-05 | Tampering | path traversal via a path-taking IPC | accept | `app:openLogs` takes no caller-supplied path — it opens `logsDir()`. No new path-taking IPC is added. If one ever is, copy `skills:reveal`'s `safeJoin`/`isWithinRoots` shape (`index.ts:3983-3991`). |
