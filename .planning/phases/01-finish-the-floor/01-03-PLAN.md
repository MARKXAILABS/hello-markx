<objective>
Close the three defects in `sweepTaskReviews` — one more than the roadmap names — so that "done"
actually means someone else checked, and pin VERDICT-03's already-satisfied behaviour with a named
test rather than rebuilding it.

Purpose: FLOOR-08 as written is satisfiable by code that reviews nothing. `sweepTaskReviews` records
the card as `done` BEFORE the loop runs, so `if (!reviewer) continue` permanently consumes the
transition edge — a card finishing while every other agent is busy is never reviewed again,
silently. And `task.review` staying truthy after a refusal means the refused-then-fixed path, where
a second look matters most, is unreviewable.

Output: an obligation `Set` (not a second state machine, not a second status field), a refuse→re-add,
a startup rebuild so an in-flight obligation survives a restart, and three tests.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| claimant agent → task board `status: 'done'` | An agent asserts its own work is finished. The review sweep is the only thing that makes that assertion checkable by someone else. |
| reviewer agent → `applyReviewVerdict` | A second agent's verdict mutates card state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-P03-01 | Repudiation | `sweepTaskReviews` consumed transition edge | mitigate | The obligation `Set` makes "nobody was free" a retry rather than a permanent silent skip — an unreviewed card can no longer disappear without a record (VERDICT-02). |
| T-P03-02 | Repudiation | refused-then-fixed card never re-reviewed | mitigate | Re-add the id on the refuse branch of `applyReviewVerdict`, so the path where a second look matters most is not silently unreviewable. |
| T-P03-03 | Spoofing | an agent reviewing its own work | mitigate | Already shipped: `leastLoadedIdle([task.assignee])` excludes the assignee. Pinned by the new tests; do not weaken the skip list. |
| T-P03-04 | Information disclosure | review query routed to an engine that cannot receive mail | mitigate | Already shipped at `hive.ts:1746`; pinned by a named test (VERDICT-03). No code change. |
| T-P03-05 | Denial of service | obligation set grows unbounded across restarts | mitigate | Rebuild from the live task board at startup and bound by card lifetime — an obligation for an archived or deleted card is dropped. |
| T-P03-06 | Denial of service | review storm (re-querying a card under review every minute) | mitigate | The `task.review` open-review guard is preserved; `test/hive-protocol-v2.test.cjs:233` is the regression test and must stay green. |
</threat_model>
