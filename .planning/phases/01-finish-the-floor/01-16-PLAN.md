- **Rule 0** — decorative glyph on the frozen allowlist: size unchanged, element gains `aria-hidden="true"`. Stop.
- **Rule 1** — the style object sets `fontFamily: 'var(--cth-font-display)'` AND a `fontSize` of 7-13:
  `fontSize` → `var(--cth-text-display-md)`, `lineHeight` → `var(--cth-lh-display-md)`.
  **`fontFamily` is UNCHANGED — Press Start 2P stays.** `DESIGN.md:706` is a size rule; converting the
  display face would retire a typeface, which this contract's second paragraph forbids.
- **Rule 2** — `fontSize` 7-13 with no `--cth-font-display` in the same object: → `var(--cth-text-body-md)`,
  or `var(--cth-text-mono-md)` where the object sets `fontFamily: 'var(--cth-font-mono)'`, with the
  matching `--cth-lh-*` token. The mono line-height token is the single `--cth-lh-mono`.
- **Rule 1b and Rule 3 do not apply to this group.**

**Pinned measurement command (M1). Do not re-derive with a different regex:**
`grep -rnE "fontSize *[:=] *\{?(1[0-3]|[1-9])($|[^0-9.])" <file>`

**Rule 0 candidates in this group: none** per UI-SPEC's 30-candidate table. Verify in task 1 rather
than assuming; if the re-run finds one, apply Rule 0 and add it to this group's allowlist.

**Hoisted shared style objects are NOT exempt.** Sweep the shared declaration normally and give any
glyph-only consumer a **local `fontSize` override**; that override's line is the allowlist entry.

**Accessible names — the rule, not the ratio.** Visible text content → **already named, do NOT add
`aria-label`**. Icon/glyph/symbol only → `aria-label` required, phrased verb + object
(`FullscreenTerminal.tsx:665` is the house pattern). `PixelButton` renders real button text, so a
labelled `PixelButton` needs nothing.

**Containment — UI-SPEC's three steps, in order:** (1) do nothing where `nowrap` + `overflow:hidden` +
`textOverflow:ellipsis` already truncates; (2) raise the container's integer by the measured delta and
change nothing else; (3) **stop and report** with the file:line and the measured overflow.
**Explicitly forbidden:** reflowing, moving a field, dropping a field, collapsing a row, or holding any
site below 14px to make room.

**Note on `OnboardingWizard.tsx`:** it carries one of the nine `react-hooks/exhaustive-deps` disable
comments that plan 20 (FLOOR-16) turns into a live suppression. **Do not delete or move that comment.**
A size sweep has no reason to touch it, and moving it off its target line would break the suppression.
The same caution applies to any `eslint-disable-next-line` comment in this group's files.

**Out of the sweep entirely:** `components/terminalFontSize.ts` and anything xterm.
