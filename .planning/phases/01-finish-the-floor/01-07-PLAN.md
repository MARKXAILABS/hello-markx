<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer → main delivery decisions | Autonomy that lives in the renderer dies with the window. Anything moved to main crosses from "the human is watching" to "nothing is watching", which is the trust property this phase exists to establish. |
| main → agent PTY (a write into a terminal) | ADR-0001's one-gate rule governs anything that types into a terminal; the quiesce backstop must not become a second writer. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-P07-01 | Denial of service | an agent stuck `working` forever with the window closed | mitigate | The quiesce backstop moves into `delivery.ts`'s tick, where it runs with no window attached; covered by a fake-clock test that asserts the flip with `emit` a no-op. |
| T-P07-02 | Tampering | the backstop becoming a second PTY writer | mitigate | It only flips status; ADR-0001's one-gate rule is preserved because the backstop writes no terminal bytes. State this in the code comment. |
| T-P07-03 | Repudiation | docs asserting a live security-relevant path is dead | mitigate | Delete HIVE.md's four denials and pin both directions in `test/repo-claims.test.cjs` — absence of the stale strings AND presence of the live wiring. |
| T-P07-04 | Denial of service | deleting the working Stop-drain because the roadmap called it dead | mitigate | Task 1's pasted `drainAtStop` grep is a hard gate before any edit; the plan states explicitly that this clause is already satisfied and must not be touched. |
| T-P07-05 | Repudiation | a quiesce flip that the operator cannot see because no window is attached | accept | `emit` is a documented no-op with no webContents; the flip is still recorded in the hive log. Surfacing it to a closed window is DAEMON-01's problem (Phase 2), not this phase's. |
</threat_model>
