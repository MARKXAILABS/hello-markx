<objective>
Replace the single floor-wide hook socket secret with per-agent tokens minted per spawn and bound
to `agent_id` **server-side**, and discard `payload.agent_id` entirely.

Purpose: GATE-01. `hooks.ts:11-18` calls this socket the app's one local trust boundary. PR #76
fixed the half that was simply broken. What remains is the security half: one secret, spread into
every PTY by `pty.ts:665`, readable by every LLM-controlled shell. Against a prompt-injected agent
the check currently buys nothing, and every record, review and recall written afterwards inherits
that weakness.

Output: a `Map<token, agentId>` in `HookServer`, per-spawn env injection, the mandatory deletion
of `index.ts:5534`, and a real-socket test that an impersonation attempt fails.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| agent PTY (LLM-controlled shell) → hook socket / named pipe | THE local trust boundary this repo names at `hooks.ts:11-18`. Everything past `authorized()` decides whose session, ledger and breaker gets written. |
| any local same-uid process → the socket | The socket is reachable by any local process; the token is the only gate. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-P02-01 | Spoofing | `hooks.ts` `authorized()` + `payload.agent_id` | mitigate | Derive `agentId` from a `Map<token, agentId>` server-side and discard `payload.agent_id` entirely (D-11). |
| T-P02-02 | Spoofing | `pty.ts:665` `...process.env` spread of a floor-wide secret | mitigate | Delete `index.ts:5534` (D-12) and mint per-agent tokens into each spawn's `opts.env`; pinned by a source-grep test. |
| T-P02-03 | Spoofing | qwen proxy-bridge sidecar spawned with `...process.env` | mitigate | D-13 — pass that agent's token explicitly at the sidecar spawn site, or the sidecar goes silently dead-hooked. |
| T-P02-04 | Spoofing | timing attack on the token compare | mitigate | Keep `sha256(` + `timingSafeEqual` (already landed, `node:crypto`, never hand-rolled); introduce no `.length` comparison — `test/net-binding.test.cjs:217-232` greps for both. |
| T-P02-05 | Repudiation | overclaiming secrecy in docs/UI | mitigate | D-14 — the header states impersonation resistance, not secrecy. An agent's own shell can always read what its own shim can read. |
| T-P02-06 | Tampering | cost-ledger / session poisoning via a forged payload | mitigate | Same token gate; plan 06's FLOOR-09 rewiring must stay behind `authorized()`. |
| T-P02-07 | Elevation of privilege | non-descendant local attacker connects to the socket | accept | Socket peer-credential binding has no supported Node API (nodejs/node#7627) and would mean a native addon on three CI gates. D-15 rejects it with reasons; deferred, not forgotten. |
| T-P02-08 | Tampering | hook payload replay | accept | HMAC/nonce adds freshness but not impersonation resistance; `PI_EXTENSION`/`OPENCODE_PLUGIN` are fire-and-forget so challenge-response is impossible without restructuring. Deferred (D-15). |
</threat_model>
