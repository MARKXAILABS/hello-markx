<objective>
Replace the single floor-wide hook socket secret with per-agent tokens minted per spawn and bound
to `agent_id` **server-side**, and discard `payload.agent_id` entirely.

Purpose: GATE-01. `hooks.ts:11-18` calls this socket the app's one local trust boundary. PR #76
fixed the half that was simply broken. What remains is the security half: one secret, spread into
every PTY by `pty.ts:665`, readable by every LLM-controlled shell. Against a prompt-injected agent
the check currently buys nothing, and every record, review and recall written afterwards inherits
that weakness.

Per-agent tokens alone do not finish the boundary. **Five** holes sit beside them, all re-verified
against current source this session (1-3 were known; 4 and 5 were added after red-team round 3 found
the first three under-specified and the socket unnamed anywhere in the phase):
1. The qwen proxy sidecar (`hive.ts:1170-1223`) is spawned with `...process.env` and names no token
   of its own — it lives on the floor-wide value this plan deletes. Its spawn site is in `hive.ts`,
   which this plan may NOT edit and which cannot compile against this plan's mint until the next
   wave; the change is named and handed to plan 06 (wave 3), not smuggled.
2. ONE `<hiveRoot>/bin/cth-hook.cjs` runs inside EVERY agent's hooks (`hive.ts:681-684`) and nothing
   in `AGENT_DENY_RULES` (`hive.ts:383-420`) protects it. Agent A appending four lines to that file
   harvests agent B's token from inside B's own hook — per-agent identity, defeated in one write.
3. Four documents describe the floor-wide design. Shipping this plan without them makes the repo's
   own trust-boundary claim false.
4. **The socket itself is fail-open on deletion, and rebindable.** `hooks.ts:159` listens once and
   nothing re-listens; the shims exit 0 on a connect error and exit 0 with no stdout is *allow*; plain
   `rm` is not in `AGENT_DENY_RULES`. So `rm "$HIVE_ROOT/hooks.sock"` disables the whole PreToolUse
   gate floor-wide until app restart — and an agent that then BINDS that fixed path collects every
   other agent's token and answers `allow` to everyone. Both properties this plan buys die in one
   command, and no plan in this phase named the second before now.
5. **Three of the six shim templates send no `sock_token` at all** (`PI_EXTENSION`,
   `OPENCODE_PLUGIN`, `PROXY_BRIDGE_SHIM`) and all three reach `authorized()`, so pi, opencode and
   the qwen sidecar are already dead-hooked at HEAD. An earlier revision of this plan asserted all
   six read the token and needed no body change; that was false, and it is what made the wave-3
   sidecar env fix a no-op that still passed every criterion.

Output: a `Map<token, agentId>` in `HookServer`, per-spawn env injection, the mandatory deletion
of `index.ts:5534`, a PreToolUse write gate over the WHOLE protected set (`bin/`, `.git/`, the
socket, other agents' directories) with symlink and `$HIVE_ROOT`-literal resolution, a socket
watchdog that re-listens rather than failing open, three corrected documents, a repaired
`test/hook-auth-roundtrip.test.cjs`, and a real-socket test that impersonation and every protected
write both fail.
</objective>
