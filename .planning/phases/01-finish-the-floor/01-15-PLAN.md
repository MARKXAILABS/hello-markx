**Sweep rules (UI-SPEC, checked in order):**
- **Rule 0** — decorative glyph on the frozen allowlist: size unchanged, element gains `aria-hidden="true"`. Stop.
- **Rule 1** — the style object sets `fontFamily: 'var(--cth-font-display)'` AND a `fontSize` of 7-13:
  `fontSize` → `var(--cth-text-display-md)`, `lineHeight` → `var(--cth-lh-display-md)`.
  **`fontFamily` is UNCHANGED — Press Start 2P stays.** `DESIGN.md:706` is a size rule.
- **Rule 2** — `fontSize` 7-13 with no `--cth-font-display` in the same object: → `var(--cth-text-body-md)`,
  or `var(--cth-text-mono-md)` where the object sets `fontFamily: 'var(--cth-font-mono)'`, with the
  matching `--cth-lh-*` token. Note the mono line-height token is the single `--cth-lh-mono`.
- **Rule 1b and Rule 3 do not apply to this group** — their five sites all belong to plan 14.

**Pinned measurement command (M1). Do not re-derive with a different regex:**
`grep -rnE "fontSize *[:=] *\{?(1[0-3]|[1-9])($|[^0-9.])" <file>`

**Rule 0 candidates in this group: none.** UI-SPEC's 30-candidate table lists no glyph-only element in
any of these five files. Verify that in task 1 rather than assuming it — if the re-run finds one, apply
Rule 0 and add it to this group's allowlist.

**Hoisted shared style objects are NOT exempt.** Where a hoisted object serves both a glyph-only
element and any text element, sweep the shared declaration normally and give the glyph a **local
`fontSize` override**; that override's line is the allowlist entry. Allowlisting the shared declaration
would leave real text below the floor with the test green.

**Accessible names — the rule, not the ratio.** Every `<button>` must have an accessible name.
Visible text content → **already named, do NOT add `aria-label`** (it overrides the visible label and
makes voice control worse). Icon/glyph/symbol only → `aria-label` required, phrased verb + object.
`FullscreenTerminal.tsx:665` is the house pattern. `PixelButton` renders real button text, so a
`PixelButton` with a label needs nothing.

**Containment — UI-SPEC's three steps, in order:** (1) do nothing where `nowrap` + `overflow:hidden` +
`textOverflow:ellipsis` already truncates; (2) raise the container's integer by the measured delta and
change nothing else; (3) **stop and report** with the file:line and the measured overflow.
**Explicitly forbidden:** reflowing, moving a field, dropping a field, collapsing a row, or holding any
site below 14px to make room. If the answer looks like "redesign it", it is option 3.

**Note for `SettingsModal.tsx`:** plan 10 added the Log folder row (FLOOR-05) and it was written at the
corrected size deliberately. Do not sweep it again or "normalise" it back down. Its neighbouring
section-header style at `:882-886` uses `fontSize: 8` and IS in scope.

**Out of the sweep entirely:** `components/terminalFontSize.ts` and anything xterm.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| rendered settings UI → operator configuration decisions | Settings is where the operator turns auto mode on, sets budgets and manages accounts. Text too small to read, or a control with no accessible name, is a misconfiguration risk on the highest-consequence surface in the app. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-P15-01 | Information disclosure | settings text below the legibility floor | mitigate | Every site swept to a token; the per-file M1 count must equal the allowlist size. |
| T-P15-02 | Information disclosure | an icon-only control with no accessible name in the settings surface | mitigate | Per-element `aria-label` pass driven by a pre-built inventory, never a ratio assertion. |
| T-P15-03 | Denial of service | a bumped label clipping and hiding a setting's current value | mitigate | Containment applied in UI-SPEC's order with measured deltas; "stop and report" rather than reflow. |
| T-P15-04 | Repudiation | an `aria-label` added over a visible button label, silently degrading voice control | mitigate | The inventory marks NAMED entries explicitly and the acceptance criteria require each added label to map to an ICON-ONLY entry. |
| T-P15-05 | Repudiation | allowlisting a hoisted style object and leaving real text below the floor | mitigate | Hoisted objects are swept at the declaration and glyph consumers get local overrides; the per-file count check would fail otherwise. |
</threat_model>
