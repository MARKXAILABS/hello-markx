<objective>
Turn `src/main/index.ts`'s composition root into an injectable `bootFloor(deps)` under
`src/main/floor/`, so the floor can be constructed and torn down with no Electron binary — and so
DAEMON-01 has something to be verified against.

Purpose: STRUCT-01, the first half of the phase's internal gate. **D-02 changes what this extraction
is for.** The roadmap says `index.ts` "imports `electron`, so it cannot be loaded under `node --test`".
Measured: `node -e "require('./test/load-ts.cjs')('src/main/index.ts')"` gets **past** the import
(the loader has shipped an electron stub since issue #55), **executes `initFileLogging()` for real**,
and dies at `app.on is not a function` — `index.ts:188`. The blocker is module-scope side effects.
So a split that moves 3,000 lines into new files which still construct singletons at import time buys
nothing and would pass a line-count gate. The criterion is a green `test/boot-floor.test.cjs`.

**The prelude cannot be sliced.** `index.ts:106-1055` declares every singleton *and* its dependency
object in one topologically-ordered block — `hive` at `:365` is read by `telemetry`'s `resolveCwd` at

at `:444`, by `hookServer` at `:544`, by `memory` at `:560`, by `reflector` at `:591`. Initialization
order **is** the dependency graph. This is one plan, one owner, one commit.

Output: two new electron-free modules, an `index.ts` whose `whenReady` body is `bootFloor(...)` plus
IPC registration, and the gate's own test file.
