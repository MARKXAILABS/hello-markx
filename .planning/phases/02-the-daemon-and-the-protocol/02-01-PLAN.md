Split `src/main/hive.ts` along the four seams its own section markers name — shim templates, the git
committer, provider provisioning, and (by leaving it addressable) the router — so that the five later
Phase 2 plans that must touch this file are not four agents editing one 4,121-line module.

described:** the roadmap's rationale ("the extraction is what turns 'runs headless' from a claim into
a test") is true of `index.ts` and **false of `hive.ts`**, which `engine-parity`, `hive-cwd`,
`hive-durability`, `hive-hook-node` and `hive-protocol-v2` already load under `node --test` today.

router, the per-provider installers and the template literals, and this phase opens that seam
regardless. Do not repeat the testability claim for this file anywhere.

Output: three new electron-free modules, a `HiveManager` whose public API is byte-for-byte
unchanged, the repo's first router test, and two repo-fact clauses that go red if the split is undone.
