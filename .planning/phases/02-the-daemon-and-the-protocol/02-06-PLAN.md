Purpose: PARITY-01b and DAEMON-04's UI half. **D-30 is the measured fact this plan exists for:**
`capabilityLine()` has zero production consumers — `src/main` 0, `src/renderer` 0, `src/preload` 0 —

five clauses of mostly-good-news on a 322px card is the wall of warnings the surface must not become.

`--mcp-config` on the spawn argv. This plan is where the operator **grants** a server and where the
card afterwards **admits** which servers that agent holds — with `⚿` (keyed), `⚠` (granted, no key,
not armed) and `↻` (granted, not yet in effect) kept distinct, because no engine is confirmed to
hot-reload (D-29) and a card showing a live connection that does not exist is the exact class of lie
this project bans.

### The landmines, measured against live source

**`process.platform` does not exist in the renderer — it is a ReferenceError, not `undefined`.**
`providerCapabilities` calls `remoteControlAvailability(provider)` (`providerAutomation.ts:300`) whose
signature is `remoteControlAvailability(provider, platform: string = process.platform)` (`:284-287`),
and a default parameter is evaluated on **every** call where the argument is omitted, before any body
short-circuit. **Both** functions therefore need the platform passed: `capabilityGaps` calls
`providerCapabilities(provider, platform)` **and**, for the two `NO REMOTE` sentences,
`remoteControlAvailability(provider, platform)`. Passing it to one and not the other throws on first
paint on every non-claude, non-codex engine.

**`agentRowForCard` can return `undefined`.** `store/autoMode.ts:119-131`: with no `ptyId` and an
ambiguous name it returns nothing — *"better nothing than the wrong agent"*. And
`inferAgentProvider(undefined, undefined)` returns **`'claude'`**. So a card that falls back to the
inferred provider paints Claude's capability profile onto an unknown agent. **No row ⇒ no chip and no
MCP element.** Silence is the honest render; a claude profile is a fabricated one.

**`useSyncExternalStore`'s `getSnapshot` must be referentially stable.** `getLiveAutoMode` returns a
boolean, so `autoMode.ts` gets this for free. A grants map does not: returning a fresh object literal
from `getSnapshot` re-renders forever. Cache the snapshot object and replace the reference only in the
publisher.

**The card's height is frozen at 86px** and propagates to `AgentStrip.tsx:270-271`'s `height: 120`,
which is space taken from the Pixi office scene. Everything this plan adds rides **existing rows**.
If the executor concludes the card must grow, that is a **stop-and-report**, not a decision to make in
flight (UI-SPEC § Containment Protocol).

**`⚿` (U+26BF) and `↻` (U+21BB) have never been rendered by this repo.** Both are BMP and both sit
near glyphs the app already ships (`☀` U+2600, `☾` U+263E, `⇄` U+21C4), so they are *expected* to
resolve in Segoe UI Symbol — but "expected" is not this project's bar. Live CDP width check, and if
either fails the substitution is **prescribed, not improvised**: `⚿` → the word `key`, `↻` → the word
`restart`, both at `var(--cth-text-body-sm)`. Do not substitute a different symbol.

**`restartWithModel` is a 90-line local closure in `CommandCenterPanel.tsx:434`**, not an export. It
disposes and re-acquires the terminal, bumps `terminalGeneration`, resolves the Claude account pin and
its policy, and hard-fails when a resume is refused (`:505-560`, `:920`, `:1021`). D-29's modal offers
`restart {name} now`. **A second copy of that flow is forbidden** — this codebase's own comment for the
auto-mode derivation says *"three copies of a safety rule are three chances to start lying"*. The modal
therefore takes an optional `onRestart` callback, and only a launch point with a correct implementation
in scope supplies it. See task 4.

**The naive two-argument grep passes vacuously.** `providerCapabilities\(([^()]*)\)` against
`providerCapabilities(inferAgentProvider(a.command, a.provider))` captures
`providerCapabilities(inferAgentProvider(a.command, a.provider)` — which contains a comma, so a
"has a comma ⇒ two arguments" test reports PASS on a **one-argument** call. That is D-40's third
instance reproduced exactly. Scan paren depth; split on depth-1 commas.
